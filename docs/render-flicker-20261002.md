# 云端渲染闪烁处理（2026-10-02）

## 排查与处理

用户报告云端画面闪烁。公网部署入口的 app.js 和
supersplat-preview.js 与本地版本一致，接口与模型读取正常。
SuperSplat 1.36.2 默认请求 WebGPU；其内置 PlayCanvas 2.22.6 在此路径
使用 GPU 高斯排序，WebGL2 使用 CPU Worker 排序。GPU 投影阶段通过原子
计数紧缩可见高斯，深度键相同时，其输入顺序可能影响透明混合结果。
这是代码层面的风险判断，并非已在用户设备上确认的唯一根因。

当前测试浏览器没有可用的 WebGPU adapter，旧版自动回退到 WebGL2；
无法在该浏览器直接复现用户设备的 WebGPU 闪烁。为统一设备行为，
在 SuperSplatPreview 的 createViewer 参数中明确传入 `renderer: 'webgl'`。
主视窗与辅助封面实例都经过同一入口。原始依赖与相机适配器保持现有版本。
绘制仍由 GPU 完成；大型模型的 CPU 排序可能较 WebGPU 慢。
