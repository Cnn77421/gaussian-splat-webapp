# 场景爆开入场

加载生成结果或导入本地 PLY 后，真实高斯粒子会聚合到模型中心。点击画面或聚焦展开按钮后按 Enter，粒子立即扩散，经过旋流、轻微回弹和颜色恢复，约 1.75 秒落回完整场景。配合光晕、轨道、瞬时闪光、扩散环和短暂镜头后退。

等待状态的光核有差速旋转、流动亮纹、独立闪烁和轻微呼吸。16% 的场景粒子组成三组倾斜轨道，沿外围绕行，点击时与其余粒子一起归位。球面使用均匀方向采样，细化粒子尺寸，以蓝白光为主、少量金色闪光点缀。画面不显示介绍文案。

右下角可跳过；完成后可重播。重播保持观看方向、距离和视角平面，将旋转中心移回模型中心。动画暂停相机手势、自动旋转和鼠标形变；结束后恢复原有控制状态。系统设置减少动态效果时，直接显示场景并隐藏动画入口。

## 接入和调节

- `web/scene-intro.js`：Spark Dyno GPU 修饰器、状态机、控件、资源清理。`INTRO_DURATION` 控制时长；GLSL 的 `expansion`、`flight`、`reveal` 控制扩散、旋流和颜色恢复。
- `web/scene-intro.css`：独立光晕、轨道、闪光、冲击环和提示样式；模块按需加载。
- `SparkViewer.addSplatScene(url, { intro: true })` 开启动画。默认关闭，保留其他集成调用和已有验证页面的行为。
- `app.js` 的生成结果与本地 PLY 入口传入 `intro: true`。

修饰器在已有粒子特效之后执行，关闭时直接传递原始输入，不修改 PLY 文件或训练数据。切换模型和销毁查看器时，清理动画元素、监听器和相机控制锁。镜头冲击仅作用于临时渲染相机，基础机位不累计偏移。
