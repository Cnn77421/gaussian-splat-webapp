## 评委追问的回答口径

- **你们自己做了什么？** 重建复用 OOOSplat、COLMAP 和 Brush，主查看器复用 SuperSplat / PlayCanvas。团队贡献应落到实际实现的任务流程、作品管理、相机适配、粒子交互、质量诊断与行为验证；不把底层重建算法说成自主研发。
- **多久能生成？** 给出选定素材、质量档位、机器和实测口径。第 12 页是引擎累计耗时；现场等待时间还可能包含上传、排队和浏览器加载。
- **GPU 是否加速整个重建？** 当前 GPU 入口加速 SIFT 特征提取与匹配，Mapper 仍采用 CPU 优化；训练由 Brush 执行。没有相同条件下的完整对照，不宣称固定加速倍数。
- **成功是否代表画质好？** 任务成功和相机注册率只能说明流程与覆盖情况，视觉质量需要看真实模型。当前首屏画面是需要优先改善的展示问题。
