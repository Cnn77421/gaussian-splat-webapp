# 按模型计算源视角（2026-10-02）

当前主页面已使用 SuperSplat，旧 `app.js:147` 的固定样本向量移到了预览适配器和原有控制。此次移除这两处固定向量，并修复全局水平面迁移。

## 当前行为

- 生成任务带 `sourceView` 时，使用实际训练数据集第一张已注册拍摄画面的相机位置、方向、朝上向量和焦距。按图片名、图片 ID 排序，不使用 COLMAP 注册顺序。原版首帧与原有控制的“源视角”采用同一套数据，保留拍摄倾斜角。
- 缺少拍摄相机信息的旧任务与独立 PLY：在剔除远处飞点后的模型上计算主轴，选择厚度最小方向取景，按实际画布比例投影包围盒角点，适配横竖屏。按钮显示“初始视角”，不会将几何估计冒充拍摄机位。模型几何无法唯一恢复真实拍摄方向。
- 默认视角、水平面继续以模型键单独保存；保留用户已有的模型设置。停止把旧的全局 `splat.viewPlaneUp` 分配给升级后第一个打开的模型，因为该值没有可靠的模型身份。
- 恢复水平面使用本模型的初始朝上方向；已有用户保存平面优先于计算值。

## 相机数据保留

`server.py` 在任务标记完成及清理 `work/` 之前读取 Brush 使用的 COLMAP 相机。根据实际训练报告选择普通或去畸变数据集，避免读到旧去畸变缓存。只保存小型 `source-view.json` 和任务的 `sourceView` 字段，不保留大体积中间文件。

坐标遵循本地 COLMAP 文档 `gpu-build/colmap-4.2.1/doc/format.rst`：`C=-Rᵀt`，前方为 `RᵀZ`，朝上为 `Rᵀ(-Y)`。浏览器再应用 SuperSplat 对 PLY 的 180° Z 轴显示旋转一次。启动清理也会先保留有相机数据的旧任务；已经删除的相机文件无法补回。

主服务未重启，避免干扰其他任务。前端刷新可使用新几何取景；后端的相机保留逻辑在下一次正常重启后生效。
