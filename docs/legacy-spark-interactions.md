# 迁移前 Spark 交互记录

以下内容描述迁移前的实现，不是当前展示页的功能。

## 视角与粒子交互

现有网页已迁移到 [Spark](https://github.com/sparkjsdev/spark)，旧的整团旋转、散开和随机抖动 Shader 已移除。
高斯解码、GPU 数据处理、透明排序和渲染复用 Spark；鼠标与触摸相机控制复用 Three.js 的 OrbitControls。
依赖固定版本并保存到 `web/vendor/spark/`，页面不访问外部 CDN。

- 视角：拖动旋转、阻尼惯性、滚轮推进/拉远、自动环绕；可选松手 1.2 秒后缓慢回到最近预设的方向。
  回正保留当前距离，拖动时停止自动环绕。
  鼠标左键拖动旋转，中键单击点云定位新的旋转中心，中键上下拖动推进/拉远，右键拖动平移；
  中键阻止浏览器自动滚屏。定位复用 Spark 射线拾取，320ms 平滑切换中心，并显示短暂标记；
  不移动相机位置，不触发粒子脉冲，点击空白不改变中心。粒子总开关关闭及正交模式下同样可用。
- 鼠标视差：轻微位置视差与偏航，仅影响渲染相机，不往 OrbitControls 的基础机位累计偏移。
- 粒子模式：局部排斥、吸附、流体绕行、速度甩动、扭曲、涡旋、呼吸、连续噪声扰动、点击爆散、点击波纹。
  默认局部排斥；普通模式下拖动只改变视角。选择“速度甩动”才按鼠标速度拉动局部粒子。
- 形变强度、影响范围、叠加微动可独立设置；“恢复原状”或 X 回到全部初值（模式也复位为“局部排斥”）并清空脉冲残留。
  参数面板由本地 vendor 的 [Tweakpane](web/vendor/tweakpane/SOURCES.md) 4.0.5 渲染。
- “粒子特效总开关”关闭所有形变、微动和点击脉冲，立即恢复原模型；重新开启保留模式、强度和范围。
  相机和点云/高斯显示快捷键仍可使用。
- 爆散与波纹保留最近四次脉冲，自动衰减；鼠标移开后排斥/吸附/绕流平滑回归。
- 所有形变每帧基于原始粒子位置计算，避免位移累积；形变输出经过 Spark 的数据生成与排序管线。
- 指针定位复用 Spark 的 WASM raycast，最多约每 120ms 查询一次；查询间隔使用最近命中深度的相机朝向平面。
  没有命中时回退到环绕中心深度，不每帧对整份点云做射线查询。
- 3D 视窗全屏：工具栏的“全屏”按钮或 F 键把中间预览放到整个屏幕，视角、粒子特效和全部快捷键保持可用；
  全屏时工具栏默认收成右上角“控制”浮层按钮（需要调参数时展开，不挤压画面），Esc 或再按一次 F 退出。
  进入全屏不改变相机位置，退出后画布尺寸和相机比例自动还原。

“流体绕行”是视觉流场形变；不包含 Navier–Stokes 流体求解或粒子之间的碰撞。
大幅形变仍会暴露重建遮挡区，排序的异步更新也可能在快速运动时滞后；性能以实际模型和设备为准。
